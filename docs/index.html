What it does

8 Evaluation Criteria — All Addressed

Built against the exact Round 2 rubric. Each capability maps to a numbered criterion.

01
Material Detection & Prioritisation
C2 Op1 computes a same-weekday rolling baseline (14-day μ/σ). Op2 applies a dual gate: z-score threshold AND an absolute business floor. All five KPIs sweep on every load — ranked by severity.
C2 · DETERMINISTIC
02
Heterogeneous Data Reconciliation
C1 loads four source systems (OMS, GPS, CV, INV), applies field-level DQ validation per YAML contract, tracks staleness per source, and propagates a confidence penalty when data is stale.
C1 · SCHEMA-VALIDATED
03
Driver Identification & Ranking
C2 Op3 decomposes the KPI gap into governed drivers (from the KPI contract). Op4 segments by store and ranks contribution weight. SKU-level interval analysis confirms the stockout driver.
C2 · DECOMPOSITION
04
Persona-Specific Narratives
C4 generates two views: Zone Business Head (strategic) and Dark-Store Ops Manager (operational). Entitlement rules in C1 enforce what each persona can see — the Ops Manager never sees cross-zone GMV.
C4 · LLM NARRATIVE
05
Uncertainty & Abstention
C3 computes ms + ds + cvs − dqp + mem. Scores below LOW threshold trigger a hard ABSTAIN. The system can also QUALIFY when evidence is partial — it never fabricates certainty.
C3 · FORMULA
06
Grounded Action Recommendations
C4 reads the lever map from the KPI contract (not hardcoded). Decision rights (L1–L7) enforced by persona × lever × cost ceiling. Action package includes owner, monitoring plan, and escalation path.
C4 · CONTRACT-DRIVEN
07
Learning from Feedback
C5 stores analyst-approved findings in a DuckDB precedent store. BM25+cosine hybrid search retrieves matching precedents. Confirmed precedents boost confidence; contradictions cap it.
C5 · MEMORY
08
Security, Cost & Latency
LLM called only for narrative prose. SHA-256 in-process cache deduplicates runs. Groq Llama-3.3-70b delivers sub-2s latency. No PII leaves the local environment.
CACHE · GROQ
Transparency

Confidence is a formula, not vibes

Every confidence band is produced by an explicit, auditable equation — with live component values shown in the UI.

ms+ ds+ cvs− dqp+ mem= score → band
ms Movement significance (z-score magnitude, max 40)
ds Driver support (decomposition + CV convergence, max 30)
cvs Customer voice signal (sentiment alignment, max 20)
dqp Data quality penalty (stale/missing sources, subtracts)
mem Memory boost/cap (precedent match ±, max ±10)
HIGH ≥ 70 → Recommend
MEDIUM 40–69 → Qualify
LOW < 40 → ABSTAIN

Technical Architecture

What runs where

A clean separation between deterministic analytics and LLM generation — every boundary is explicit in code and visible in the UI audit trail.

DETERMINISTIC
Computed by code
  • Rolling 14-day same-weekday baseline (μ, σ)
  • z-score materiality gate + business floor
  • Contribution decomposition (% per driver)
  • Store segmentation + ranking by gap weight
  • KPI contract validation (YAML schema)
  • Data quality penalty calculation (−dqp)
  • Confidence score formula (ms+ds+cvs−dqp+mem)
  • Decision rights enforcement (L1–L7 levers)
  • Recoverable ₹ impact (top_driver_pct × |gap|)
  • Counterfactual computation
  • SHA-256 cache deduplication
  • DuckDB memory retrieval (BM25+cosine)
LLM · llama-3.3-70b
Generated by Groq
  • Hypothesis claim text (1–2 sentences)
  • Persona-specific narrative prose
  • Action wording (driver/lever/action field text)
  • Caveat and monitoring plan wording
⚠ The LLM is never the source of any number, percentage, confidence score, lever selection, or owner assignment. These are computed before the LLM call and passed as structured context.
